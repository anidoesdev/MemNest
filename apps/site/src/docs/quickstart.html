This uses SQLite and direct writes, so it needs no model and no database server. You will watch a fact change, and the old version step aside.

  1. Install the CLI 
    npm install -g @memnest/cli
  2. Create a database and write a fact 
    memnest migrate --db demo.db
memnest memories add "The user prefers Postgres over MongoDB for the payments database." \
  --container user:123 --db demo.db          # prints the new memory's id
  3. Write a fact that replaces it 
    memnest memories add "The user moved the payments database to MySQL." \
  --supersedes <id-from-step-2> --container user:123 --db demo.db
  4. Ask 
    memnest search "what database does this user use?" --container user:123 --budget 200 --db demo.db

    You get the MySQL memory. The trace lists the Postgres one as excluded, not-latest: still stored, no longer served.

  5. Look at the history 
    memnest memories list --all --container user:123 --db demo.db
memnest lineage <mysql-id> --container user:123 --db demo.db

Direct writes skip extraction, so you set the relation yourself with --supersedes. With a model configured, memnest ingest reads a whole conversation and works the relations out itself: see Extraction.

Or start in your chat

To give Claude, Cursor or VS Code a memory instead, with no install and no database:

claude mcp add memnest -- npx -y @memnest/cli mcp --container user:me

Ask it to remember something, then ask about it in a new conversation. Install for your client has one-click links, and Chat clients covers what the assistant can then do.
